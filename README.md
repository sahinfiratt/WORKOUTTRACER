# Fitness Tracker Pro

Bu uygulama, kullanıcıların günlük antrenmanlarını (Kardiyo, Güç/Ağırlık, Esneme) takip etmelerini sağlayan bir masaüstü yazılımıdır.

**Özellikler:**
* JavaFX ile tasarlanmış iki ekranlı kullanıcı dostu arayüz.
* SQLite veritabanı ile kalıcı veri saklama (Otomatik kurulum).
* Antrenman ekleme, listeleme, güncelleme ve silme (Tam CRUD) işlemleri.
* Hatalı girişlere karşı veri doğrulama (Input validation) kontrolleri.
* Dashboard üzerinden anlık toplam antrenman ve kalori hesaplaması.
